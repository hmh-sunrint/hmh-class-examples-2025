# QR 코드 생성기 작동 흐름

1. 사용자 입력  
   - URL 또는 텍스트  
   - QR 코드 색상  
   - 배경 색상  

2. ‘QR 코드 생성’ 버튼 클릭 → JavaScript 함수 실행  

3. 입력 값 검증  
   - 비어 있으면  
     - 경고 메시지 표시  
     - 프로세스 종료  
   - 값이 있으면  
     - 다음 단계 진행  

4. 이전에 생성된 QR 코드 제거  

5. QR 코드 라이브러리 호출 및 새 QR 코드 생성  

6. 생성된 QR 코드를 웹 페이지에 표시
