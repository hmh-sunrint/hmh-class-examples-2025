# 🧩 Firebase 링크 단축 앱 미션: 개발 흐름도

안녕! 이제 Firebase 데이터베이스의 기본 CRUD 개념을 익혔을 거야. 이번 미션에서는 우리가 함께 만들었던 링크 단축 웹 앱의 핵심 코드들을 직접 완성해 볼 거야.

`mission/` 폴더에 있는 파일들은 `template/` 폴더의 파일들과 거의 같지만, 중요한 부분들이 비어있거나 힌트만 남아있어. 너의 목표는 이 빈칸들을 채우고, 앱이 정상적으로 작동하도록 만드는 거야!

## 🎯 미션 목표

*   `mission/index.html`, `mission/style.css`, `mission/script.js`, `mission/404.html`, `mission/app.js` 파일을 써서 링크 단축 웹 앱을 완성해봐.
*   Firebase 프로젝트 설정, 인증, Firestore 데이터 저장 및 조회 로직을 직접 구현해봐.
*   `template/` 폴더의 파일을 참고해서 문제를 해결하고, 각 코드의 의미를 이해해봐.

## 🛠️ 준비물

*   웹 브라우저 (크롬, 파이어폭스 같은 거)
*   텍스트 에디터 (VS Code 같은 거)
*   **너의 Firebase 프로젝트 설정 정보** (API 키, 프로젝트 ID 같은 거)
*   `template/` 폴더의 파일들 (참고용으로 써봐!)

## 📝 미션 과정 (개발 흐름도)

이 흐름도를 따라가면서 미션을 진행하면 돼. 각 단계별 자세한 코딩 과제는 `mission/code-assignment.md` 파일을 참고해!

### 1단계: 미션 파일들 확인하기

*   `mission/` 폴더를 열어서 어떤 파일들이 있는지 먼저 쭉 훑어봐.
*   특히 `script.js`랑 `app.js` 파일을 열어보면, `// 문제 X:` 같은 주석이랑 비어있는 코드들이 보일 거야. 이게 바로 네가 채워야 할 부분들이야!

### 2단계: Firebase 프로젝트 설정 연결하기 (제일 중요!)

*   너의 웹 앱이 Firebase 데이터베이스랑 통신하려면, 너의 Firebase 프로젝트 정보를 정확히 알려줘야 해.
*   `mission/script.js`랑 `mission/app.js` 두 파일 모두에 이 설정 정보를 넣어줘야 해.

### 3단계: `index.html` 기본 정보 완성하기

*   메인 페이지인 `index.html`에서 간단한 정보를 수정하는 과제야.

### 4단계: `script.js` 핵심 로직 완성하기 (링크 단축 기능)

*   이제 링크를 입력받아서 단축 URL을 만들고, 그걸 Firebase에 저장하는 핵심 기능을 구현할 차례야.
*   Firebase 모듈 불러오기, 익명 로그인, 링크 유효성 검사, 랜덤 ID 생성, 그리고 Firestore에 데이터 저장하는 부분들을 완성해야 해.

### 5단계: `404.html` 및 `app.js` 핵심 로직 완성하기 (리다이렉트 기능)

*   단축된 URL로 접속했을 때, 원래의 긴 URL로 자동으로 이동시켜주는 기능을 구현할 거야.
*   URL에서 단축 코드를 추출하고, 그 코드로 Firebase에서 원본 링크를 찾아서 이동시키는 부분들을 완성해야 해.

## ✨ 미션 완료 후

*   모든 문제를 해결하고 앱이 제대로 작동하는지 꼭 테스트해봐.
*   새로운 링크를 단축해보고, 그 단축 URL로 접속했을 때 원래 링크로 잘 이동하는지 확인해봐.
*   Firebase 콘솔의 Firestore Database에서 네가 추가한 데이터들이 잘 저장되고 있는지 확인해봐.

이 미션을 통해 너는 실제 웹 앱 개발에서 Firebase Firestore가 어떻게 쓰이는지 깊이 이해하게 될 거야. 포기하지 말고 끝까지 해내자! 화이팅!
