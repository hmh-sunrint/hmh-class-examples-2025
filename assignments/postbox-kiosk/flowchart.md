# 택배 무인보관함 키오스크 시스템 흐름도

## 전체 시스템 구조

```
시작 (페이지 로드)
    ↓
초기화 (initializeStorage, loadData)
    ↓
메인 메뉴 화면
    ↓
┌─────────────────────────────────────┐
│  1. 택배 찾기  │  2. 택배 맡기기      │
│  3. QR코드     │  4. 보관함 현황      │
└─────────────────────────────────────┘
    ↓
각 기능별 처리 흐름
```

## 1. 택배 찾기 흐름

```
택배 찾기 선택
    ↓
택배번호 + 비밀번호 입력
    ↓
입력값 검증
    ↓
packages 배열에서 검색
    ↓
┌─── 찾음 ────┐    ┌─── 못찾음 ────┐
│ 보관함에서   │    │ 오류 메시지    │
│ 택배 제거    │    │ 표시          │
│     ↓       │    └──────────────┘
│ 성공 메시지  │
│     ↓       │
│ 메인으로     │
└─────────────┘
```

## 2. 택배 맡기기 흐름

```
택배 맡기기 선택
    ↓
받는사람 정보 입력 (이름, 전화번호, 크기)
    ↓
입력값 검증 (전화번호 형식 등)
    ↓
빈 보관함 찾기
    ↓
┌─── 있음 ────┐    ┌─── 없음 ────┐
│ 택배번호 생성 │    │ 만석 메시지  │
│ 비밀번호 생성 │    └─────────────┘
│     ↓       │
│ 보관함 할당  │
│     ↓       │
│ 데이터 저장  │
│     ↓       │
│ 성공 메시지  │
│ (번호+비번)  │
└─────────────┘
```

QR코드 인식 선택
    ↓

    ↓
시뮬레이션 버튼 클릭
    ↓
랜덤 성공/실패 결정
    ↓
┌─── 성공 ────┐    ┌─── 실패 ────┐
│ 랜덤 택배    │    │ 실패 메시지  │
│ 정보 표시    │    └─────────────┘
│     ↓       │
│ 택배찾기     │
│ 화면으로     │
│ 자동 이동    │
└─────────────┘
```

    ↓

## 핵심 함수들의 역할

1. **initializeStorage()**: 48개 보관함을 빈 상태로 초기화
2. **loadData() / saveData()**: 로컬 스토리지와 데이터 동기화
3. **showScreen()**: 화면 전환 관리
4. **pickupPackage()**: 택배 찾기 로직
5. **depositPackage()**: 택배 맡기기 로직
6. **renderStorageGrid()**: 보관함 시각화
7. **showNotification()**: 사용자 알림 표시

이렇게 각 기능들이 유기적으로 연결되어 전체 키오스크 시스템이 동작하게 돼!
```
