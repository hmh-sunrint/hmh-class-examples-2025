# 🎴 카드 플립 명함 만들기 - 숙제 안내

## 🎯 미션 목표
클릭하면 뒤집히는 3D 카드 명함을 완성해보자! 너만의 개성 넘치는 명함을 만들어보셈!

## 📝 해야 할 일들

### 1단계: HTML 개인정보 입력하기
**index.html 파일에서 다음 부분들을 채워넣으셈:**

- [ ] **타이틀 변경**: `<title>[당신의 이름]님의 카드스냅</title>` → `[당신의 이름]` 부분을 너의 이름으로 바꿔.
    -html
    <title>홍길동님의 카드스냅</title>
    -
- [ ] **프로필 이미지**: `<img src="/placeholder.svg?height=100&width=100" alt="profile" style="width:37%;">` → `src` 속성에 너의 사진이나 아바타 이미지 경로를 넣어.
    -html
    <img src="images/my_profile.png" alt="profile" style="width:37%;">
    -
- [ ] **이름 입력**: `<h2>[당신의 이름]</h2>` → `[당신의 이름]` 부분을 너의 이름으로 바꿔.
    -html
    <h2>홍길동</h2>
    -
- [ ] **직업/역할**: `<p>[직업/역할] 🔧</p>` → `[직업/역할]` 부분을 너의 직업이나 꿈을 적어.
    -html
    <p>프론트엔드 개발자 🔧</p>
    -
- [ ] **기술스택 4개**: `<p class="rounded_p">💾 | 커리어1</p>` 등 4개의 `커리어` 부분을 너의 경력이나 기술스택으로 바꿔.
    -html
    <p class="rounded_p">💾 | 웹 개발</p>
    <p class="rounded_p">📱 | 모바일 앱</p>
    <p class="rounded_p">🖥️ | 데이터 분석</p>
    <p class="rounded_p">🖥️ | 게임 개발</p>
    -
- [ ] **소셜미디어 링크**: 유튜브, 인스타그램, 페이스북 링크를 너의 것으로 바꿔. `href` 속성 값을 수정하면 돼.
    -html
    <a href="https://youtube.com/yourchannel" style="color: aliceblue;">유튜브채널</a>
    <a href="https://instagram.com/youraccount" style="color: aliceblue;">인스타그램</a>
    <a href="https://facebook.com/yourpage" style="color: aliceblue;">페이스북</a>
    -
- [ ] **지도 임베드**: 구글맵에서 너의 학교나 집 근처 지도 임베드 코드를 가져와서 `<iframe src="..."` 부분을 바꿔.

    **구글 맵 임베드 코드 가져오는 방법:**
    1. **구글 맵스 접속**: 웹 브라우저에서 [Google Maps](https://maps.google.com/)에 접속해.
    2. **위치 검색**: 지도에서 너가 원하는 위치(예: 학교, 집, 좋아하는 카페)를 검색해.
    3. **공유 버튼 클릭**: 검색된 위치 정보 패널에서 '공유' (Share) 버튼을 찾아 클릭해.
    4. **지도 퍼가기 선택**: 팝업 창에서 '지도 퍼가기' (Embed a map) 탭을 선택해.
    5. **HTML 복사**: 'HTML 복사' (Copy HTML) 버튼을 클릭해서 `<iframe>` 태그로 시작하는 코드를 복사해.
    6. **코드 적용**: 복사한 코드를 `index.html` 파일의 `<!-- TODO: 구글맵 임베드 코드를 자신의 위치로 변경하세요. -->` 주석 아래에 있는 기존 `<iframe>` 태그 대신 붙여넣어. `width`와 `height`는 기존 값(200, 150)을 유지하는 게 좋아.

### 2단계: CSS 스타일 완성하기
**style.css 파일에서 빈칸들을 채워넣으셈:**

- [ ] **Perspective 설정**: `.card` 선택자 안의 `perspective: 1000px;` 주석을 참고해서 값을 넣어. (3D 효과용)
    -css
    .card {
      perspective: 1000px; /* 3D 공간을 만드는 값이야. */
      /* ... */
    }
    -
- [ ] **배경색 변경**: `body` 선택자 안의 `background-image` 속성 값을 너가 좋아하는 색상 조합의 그라데이션으로 바꿔.
    -css
    body {
      /* ... */
      background-image: linear-gradient(to left, #ff7e5f 0%, #feb47b 100%); /* 예시: 따뜻한 주황색 그라데이션 */
      /* ... */
    }
    -
- [ ] **애니메이션 시간**: `.front` 선택자 안의 `transition` 속성 값을 참고해서 시간을 넣어.
    -css
    .front {
      /* ... */
      transition: all 1.2s cubic-bezier(0.68, -0.55, 0.265, 1.55) 0s; /* 애니메이션이 1.2초 동안 부드럽게 재생돼. */
    }
    -
- [ ] **회전 각도**: 
  - `.front.horizontal.front-visible` 선택자 안의 `transform: rotateY(180deg);` 주석을 참고해서 앞면이 뒤집힐 때의 Y축 회전 각도를 넣어.
  - `.back.horizontal.back-visible` 선택자 안의 `transform: rotateY(0deg);` 주석을 참고해서 뒷면이 나타날 때의 Y축 회전 각도를 넣어.
    -css
    .front.horizontal.front-visible {
      transform: rotateY(180deg); /* 앞면이 뒤로 180도 회전해서 사라져. */
      /* ... */
    }
    .back.horizontal.back-visible {
      transform: rotateY(0deg); /* 뒷면이 0도로 회전해서 정면으로 보여. */
      /* ... */
    }
    -

### 3단계: JavaScript 기능 구현하기
**script.js 파일에서 빈칸들을 채워넣으셈:**

- [ ] **클릭 조건**: `card.addEventListener("click", () => { ... if (count === 1) { ... } })` 부분에서 `if (count === 1)`의 `1`을 채워넣어.
    -javascript
    card.addEventListener("click", () => {
      count++;
      if (count === 1) { // 첫 번째 클릭일 때
        // ...
      } else {
        // ...
      }
    });
    -
- [ ] **클래스 조작**: `front.classList.add("front-visible")`와 `front.classList.remove("front-visible")` 부분에서 `add`와 `remove`를 채워넣어.
    -javascript
    // 클래스 추가
    front.classList.add("front-visible");
    // 클래스 제거
    front.classList.remove("front-visible");
    -
- [ ] **화면 표시 제어**: `document.querySelector(".card").style.display = "block"`와 `document.querySelector(".card").style.display = "none"` 부분에서 `block`과 `none`을 채워넣어.
    -javascript
    // 요소 보이기
    document.querySelector(".card").style.display = "block";
    // 요소 숨기기
    document.querySelector(".card").style.display = "none";
    -

## 💡 힌트 모음

### HTML 힌트
- 이미지 경로는 상대경로나 절대경로 둘 다 가능해
- 구글맵 임베드는 구글맵 → 공유 → 지도 퍼가기에서 가져올 수 있어

### CSS 힌트  
- `perspective` 값이 클수록 3D 효과가 약해져
- `transition` 시간이 길수록 애니메이션이 느려져
- `rotateY`는 Y축(세로축)을 기준으로 회전하는 거야

### JavaScript 힌트
- `classList.add()`는 클래스를 추가하는 메서드야
- `classList.remove()`는 클래스를 제거하는 메서드야
- `display: 'block'`은 요소를 보이게, `'none'`은 숨기게 해
