# 🎴 카드 플립 명함 만들기 - 코드 흐름도

## 📋 프로젝트 개요
- **목표**: 클릭하면 뒤집히는 3D 카드 명함 웹사이트 만들기
- **주요 기능**: 카드 플립 애니메이션, 전체화면 모드, QR코드 공유
- **사용 기술**: HTML, CSS, JavaScript

## 🔄 전체 흐름도

\`\`\`
1. 페이지 로드
   ↓
2. 전체화면 지원 확인
   ↓
3. 화면 방향 확인 (가로모드 권장)
   ↓
4. 사용자가 화면 클릭
   ↓
5. 전체화면 모드 진입
   ↓
6. 카드 표시 + 공유버튼 표시
   ↓
7. 카드 클릭 시 플립 애니메이션
   ↓
8. 공유버튼 클릭 시 QR코드 팝업
\`\`\`

## 📁 파일 구조 및 역할

### 1. index.html
- **역할**: 웹페이지의 기본 구조 정의
- **주요 요소**:
  - `#clickbait`: 전체화면 진입 전 안내 메시지
  - `.card`: 메인 카드 컨테이너
  - `.front`: 카드 앞면 (이름, 직업, 기술스택)
  - `.back`: 카드 뒷면 (연락처, 지도)
  - `.sharebtn`: QR코드 공유 버튼

### 2. style.css
- **역할**: 카드 디자인 및 애니메이션 스타일 정의
- **주요 스타일**:
  - 3D perspective 설정
  - 카드 플립 애니메이션 (transform: rotateY)
  - 그라데이션 배경
  - 반응형 레이아웃

### 3. script.js
- **역할**: 사용자 상호작용 및 동적 기능 구현
- **주요 기능**:
  - 카드 클릭 이벤트 처리
  - 전체화면 API 활용
  - QR코드 생성 및 팝업
  - 화면 방향 감지

## 🎯 핵심 학습 포인트

### 1. CSS 3D Transform
\`\`\`css
/* 3D 공간 설정 */
perspective: 1000px;
transform-style: preserve-3d;

/* 카드 회전 애니메이션 */
transform: rotateY(180deg);
transition: all 1.2s cubic-bezier(...);
\`\`\`

### 2. JavaScript DOM 조작
\`\`\`javascript
// 클래스 추가/제거로 애니메이션 제어
element.classList.add("front-visible");
element.classList.remove("front-visible");
\`\`\`

### 3. 이벤트 리스너 활용
\`\`\`javascript
// 클릭 이벤트 처리
card.addEventListener("click", function(){
  // 플립 로직 구현
});
\`\`\`

## 🚀 구현 단계

1. **HTML 구조 작성** → 카드의 앞면/뒷면 레이아웃 구성
2. **CSS 스타일링** → 3D 효과 및 애니메이션 적용  
3. **JavaScript 기능** → 클릭 이벤트 및 플립 로직 구현
4. **전체화면 기능** → Fullscreen API 활용
5. **QR코드 공유** → 외부 API 연동
6. **테스트 및 디버깅** → 다양한 기기에서 동작 확인

## 💡 주의사항
- 모바일에서는 가로모드 권장
- 전체화면 API 지원 여부 확인 필요
- CSS transform 속성의 브라우저 호환성 고려
- 애니메이션 성능 최적화 (GPU 가속 활용)
