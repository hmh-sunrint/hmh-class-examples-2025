# 키오스크 만들기 2차시 과제

## 📋 과제 목록

### 1. 타이틀 바꾸기 (HTML - index.html)
맨 위 상단에 있는 **'HMH | Head Master High-Tech'**를
**'수업용 별칭의 상점'**으로 변경하기

### 2. 본문 내용 바꾸기 (HTML - index.html)
**'HMH 부원들이 엄선한 메뉴들 입니다! 천천히 골라주세요!'**를
자신이 바꾸고 싶은 텍스트로 바꾸기
*(대신 키오스크에 들어갈만한 말이여야 함!)*

### 3. 푸터 내용 바꾸기 (HTML - index.html)
현재 저작권을 표시하는 텍스트인 **© HMH | 2025**가
화면 하단 좌측에 작게 위치하고 있다.
이를 **© HMH - \[수업용 별칭\] | 2025**으로 바꾸어보자.

### 4. 드래그 기능 방지하기 (CSS - style.css)
현재 마우스 / 터치로 텍스트나 이미지를 드래그하면 선택이되는
현상을 방지하기 *(style.css에 대놓고 답 있음!!!!)*

### 5. 푸터 색상 바꾸기 (CSS - style.css 7번째 줄)
현재 검정색으로 푸터 색이 설정되어 있는데
내가 보기엔 못생겨보여서 자신이 바꾸고 싶은 색으로 바꾸기!

### 6. 제품 2, 3을 바꾸기 (Javascript - script.js 23번째 줄 부근부터)
**'img'** 폴더에 있는 **menu-item-2.svg**와 **menu-item-3.svg**를 각각 2,3에 삽입하고 *(image)*
이미지를 보고 어울리는 상품 이름*(name)*과 설명*(description)*, 상품인식 ID*(id)* 제작하기

**좋은 예:** 제품 2 \[name\] → 크리스피 컵, 설명 2 \[description\] → 바삭한 토핑을 올린 따뜻한 컵 메뉴, 상품ID2 \[id\] ⇒ crispyCup

### 7. 새로운 상품 추가 (Javascript - script.js 48~57줄 주석 처리 해제 후 진행)
*(어려우면 패스!!)*

주석 처리 해제 후, 본인이 원하는 상품 인터넷에서 다운 or 사진 가져온 후
위의 상품처럼 정보 입력하기.

### 8. 새로고침 타이머 시간 바꾸기 (Javascript - script.js 327, 329줄)
*(어려우면 패스!!)*

이 코드는 사용자가 일정 시간동안 움직이지 않으면 자동으로 새로고침을 하는 코드이다.
바쁜 매장에서 회전율을 높히기 위해 알림창이 뜨는건 **1분**, 실제 새로고침이 되는건 **1분 20초**로 설정해보자.
**Hint:** 1000 = 1초

### 9. 안전한 데모 결제 화면 꾸미기

현재 결제 기능은 실제 결제나 외부 전송을 하지 않는 교육용 데모이다.
개인 금융정보를 입력하지 말고, 주문 금액과 데모 안내 문구가
명확히 보이도록 화면을 꾸며보자.
